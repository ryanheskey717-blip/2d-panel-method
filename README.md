## Create venv

### Mac:

```
python3 -m venv venv
source venv/bin/activate
```

```
pip install -r requirements.txt
```

### Windows:

#### powershell:

```
python -m venv venv
venv\Scripts\activate.ps1
```

#### cmd:

```
python -m venv venv
venv\Scripts\Activate.bat
```

```
pip install -r requirements.txt
```

### deactivate venv

```
deactivate
```
