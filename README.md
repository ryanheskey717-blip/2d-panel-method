# 2d-panel-method

## Create venv

### Mac:

python3 -m venv venv

source venv/bin/activate

pip install -r requirements.txt

### Windows:

python -m venv venv

powershell:

venv\Scripts\activate.ps1

cmd:

venv\Scripts\Activate.bat

pip install -r requirements.txt

### deactivate venv

deactivate
